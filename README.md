## Dataset

The NLFS `.sav` data file (approximately **310 MB**) is not included in this repository. Download it directly from the **National Bureau of Statistics (NBS) microdata portal** and place it in the location expected by the notebook. If the notebook uses a specific filename or path, make sure the downloaded file matches it, or update the path in the notebook.

- Python 3
- Jupyter Notebook or JupyterLab
- `pyreadstat`
